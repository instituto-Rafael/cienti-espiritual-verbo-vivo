## BIBLIOGRAPHIC GOVERNANCE

For each source used in a claim:

```text
source
├── exact claim supported
├── primary vs secondary
├── publication date/version
├── method / study design
├── limitations
├── replication or review status
└── current relevance check
```

### Invariants
- Citation != proof.
- Authority != infallibility.
- Review article != primary experiment.
- Cultural source != laboratory evidence.
- Legal source != scientific validation.
- Old citation != current consensus without re-checking.
