## Operational Invariants

- Observation != interpretation.
- Correlation != causation.
- Symbolic model != established mechanism.
- Legal protection != scientific validation.
- Cultural testimony != laboratory measurement.
- Hypothesis != evidence.
- Missing evidence remains an explicit gap.

## Implementation

**Phase 1 — Foundation:** methods, ethics, provenance, measurement baselines, education, and secure data infrastructure.  
**Phase 2 — Validation:** replication, external assessment, interoperability, accessibility, and community review.  
**Phase 3 — Deployment:** only validated applications advance to consequential operational use; speculative concepts remain explicitly labeled.
