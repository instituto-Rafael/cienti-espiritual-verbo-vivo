## Purpose

This repository organizes a transdisciplinary framework connecting scientific research, phenomenology, contemplative practice, ethics, cultural preservation, mathematics, technology, and legal provenance.

The operational rule is separation of evidence classes:

- observation != interpretation;
- hypothesis != evidence;
- symbolic model != established mechanism;
- cultural testimony != laboratory measurement;
- legal protection != scientific validation;
- missing evidence remains an explicit gap.

## Getting Started

### Researchers
1. Read the [Academic Framework](docs/academic/papers/00_MASTER_ACADEMIC_FRAMEWORK.md).
2. Select a [research model](docs/academic/methodologies/seven_research_models.md).
3. Review the [bibliography](docs/references/comprehensive_bibliography.md).
4. Map claims to evidence, uncertainty, provenance, and validation steps.

### Students
Use the framework as a navigation layer, not as a substitute for primary literature or empirical verification.

### Practitioners
Use only evidence-supported, professionally appropriate practices and preserve clear boundaries between research, culture, belief, and clinical care.

### Policymakers and Legal Researchers
Verify current primary legal sources before relying on any legal interpretation in the repository.
